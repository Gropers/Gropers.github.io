JDWP 恶意负载

向脚本读取的配置路径写入 JDWP 调试代理参数。使用 suspend=y 强制 JVM 启动后挂起，等待我们连接调试器。

以 Root 身份运行 Java 启动脚本。此时进程会卡在“Listening”状态，代表 Root 权限的 JVM 已准备好接受外部指令。

（需开启第二个 SSH 终端） 使用 Java 调试器连接到本地 8888 端口

在 jdb 交互界面内，由于 JVM 初始挂起，需要先设置一个断点并让程序运行到该断点，以确保 Java 核心类库（如 Runtime）加载完毕。

在断点触发后，利用 print 功能在 Root 权限的 JVM 内存中执行系统命令，为 /bin/bash 添加 SUID 权限位。

恢复 JVM 运行并退出调试器，此时提权指令已在后台由 Root 完成。

awk调用shell命令

awk可以用getline或system来调用shell的命令

1.system
system的调用形式是system(cmd).system的返回值是cmd的退出状态.如果要获得cmd的输出,就要和getline结合使用

2.getline

通过在awk内使用管道,可以把shell命令的输出传送给awk

顺便说一下getline的其他用法.
getline除了可以通过管道从shell命令里读取数据外,它还可以从标准输入(用”-“指定从标准输入读入,或者如果命令行没有任何输入文件且不用重定向符”<”指定文件,默认也是从标准输入读)和文件里读取数据;如果getline后面没有指定变量,则读取的数据会放到$0里面

如果读取成功,getline返回1;如果读到文件结束符,getline返回0;如果发生错误,例如打不开文件,getline返回-1. 所以,getline可以用于while循环中

reset-Gropers

目标信息

靶机名称: reset

难度: easy

靶机IP: 192.168.1.191

攻击机IP: 192.168.1.195(Kali Linux)

靶机地址:https://maze-sec.com/

信息收集

先进行端口扫描

只存在22和80端口

对80端口进行目录扫描

打开/index.php发现是一个登录入口

而且发现了/robots.txt存有一个邮箱

xxxggg@maze.thl

web⻚⾯漏洞利⽤

使用这个邮箱爆破密码并没有结果

丢入/forgot.php 提示邮箱存在，可以使用四位数字验证码进行密码重置

bp抓包进行爆破

结果存在IP限制,单IP一次只能试5次

那就通过修改X-Forwarded-For来伪造IP

AI写个脚本，随机IP爆破验证码

得到正确的验证码，直接修改抓到的POST包并发送请求

成功修改密码进入/dashboard.php

这个界面只有一个中英文切换可用

通过作者的提示

发现存在LFI漏洞利⽤，

访问**/var/log/auth.log**发现可以利用

LFI漏洞利⽤原理解析

/var/log/auth.log（在 Debian/Ubuntu 系 Linux 中）或 /var/log/secure（在 CentOS/RHEL 系中）用于记录系统的身份验证日志，特别是 SSH 登录记录。

当有人尝试通过 SSH 登录服务器时，无论成功与否，系统都会将登录的用户名记录到这个日志文件中。如果攻击者将一段恶意代码（例如 PHP 一句话木马）作为“用户名”进行 SSH 登录尝试，这段代码就会被原封不动地写入日志文件。

随后，攻击者通过 Web 应用程序的 LFI 漏洞去“包含（Include）”这个日志文件。如果 Web 服务器（如 PHP）解析了这个文件，它就会将日志中伪装成用户名的恶意代码当作正常的脚本执行。

使用脚本注入进行投毒

投毒成功可以执行命令，反弹shell

成功反弹并稳定shell

发现存在一个数据库先找一下他的密码

成功进入数据库

并成功得到了xxxggg的密码

root提权

发现可以进行path劫持

编写伪造的 tar，其功能是复制 bash 并赋予 SUID 权限

通过在 sudo 命令前临时修改 PATH，诱导脚本执行我们的伪造程序

成功运行被劫持的/tmp/rootbash获得了root权限
